# Tidewater React source overlay

This package replaces the Vite starter screen with the Tidewater Realty Group concept.

## Install

1. Stop the Vite server with `Control+C`.
2. Copy the contents of this folder into your existing `tidewater-realty-group` folder.
3. Allow Finder to merge folders and replace files when prompted.
4. From the project directory, run `npm run dev`.

This overlay intentionally leaves your existing `package.json`, `package-lock.json`, Oxlint configuration, and installed dependencies unchanged.
